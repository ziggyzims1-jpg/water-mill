# Knowledge is queried, never loaded into a prompt

Findings never enter a prompt; six lines saying a `recall` tool exists do. Anything read on every task is paid for on every task, so a surface that returns everything it knows gets more expensive as the factory learns and ends up switched off. `recall` returns a few one-line hits under a character budget; `detail` opens one; knowledge growing must make answers better, never bigger. A finding carries its observed date and a changed belief is superseded by a new line rather than edited, so stale findings are labelled instead of lost. Agents recall before starting (owner rule f-20260925-aa9b36, 2026-09-25). Source: `CLAUDE.md`, `docs/KNOWLEDGE.md`, `knowledge/README.md`.
